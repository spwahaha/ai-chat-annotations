## Detailed description

AI Chat Annotations makes follow-up questions precise when an AI response contains several passages you want to discuss.

Select text in a ChatGPT or Gemini response and choose “Add to question.” The selected passage stays highlighted with a numbered marker. Add an optional question or instruction, minimize it, and continue selecting other passages. When you use the provider's normal Send button or Enter shortcut, the extension includes all pending references with your message automatically.

Features:

- Collect multiple passages from earlier AI responses.
- Attach a separate question or note to each passage.
- Keep compact numbered markers anchored to their source text.
- Reopen, edit, remove, or clear pending references.
- Send references with or without additional text in the normal composer.
- Keep separate pending collections for different conversations while the page remains open.
- Use the same workflow on ChatGPT and Gemini.

Privacy by design:

- No accounts, analytics, advertising, or telemetry.
- No developer-operated server and no extension-originated network requests.
- Selected passages and notes remain in memory in the current browser tab.
- Data is sent only to the AI provider chosen by the user, through the user's normal send action.

Current limitations:

- A selection must stay within one AI response.
- Pending references do not survive a full page reload or browser restart.
- Provider interface changes may occasionally require an extension update.

AI Chat Annotations is an independent, unofficial extension. It is not affiliated with, endorsed by, or sponsored by OpenAI or Google. ChatGPT, Gemini, and their respective marks belong to their owners.
