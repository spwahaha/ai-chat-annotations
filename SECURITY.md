# Security Policy

## Supported versions

The latest version published in the Chrome Web Store is supported.

## Reporting a vulnerability

Do not include private chat content, credentials, cookies, or authentication tokens in a public report. Open a minimal security report at:

https://github.com/spwahaha/ai-chat-annotations/issues

If public disclosure would create immediate risk, first open an issue containing no exploit details and request a private communication channel.

Reports should include the affected version, browser version, supported provider, reproduction steps using non-sensitive content, and the potential impact.
